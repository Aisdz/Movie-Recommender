## 📌 Project Overview

A content-based movie recommendation system built with Python.
Analyzes movie plots, genres, directors, and cast to recommend similar movies.

---

## How it works

1. Text preprocessing — cleaning metadata
2. Feature engineering — building a weighted "soup" string
3. TF-IDF vectorization
4. Cosine similarity computation
5. Genre-based filtering
6. Top-10 recommendations output

## 📁 Project structure

```
├── app.py                     # Streamlit web app
├── Movie_preprocessing.ipynb  # Run this first to generate model files
├── movie dataset.csv          # Dataset (download separately, see below)
├── movies.db                  # Generated by notebook
├── tfidf_matrix.pkl           # Generated by notebook
├── indices.pkl                # Generated by notebook
└── README.md
```
> ⚠️ `movies.db`, `tfidf_matrix.pkl` and `movie dataset.csv` are not included in the repo.
> You need to generate them yourself by following the steps below.

## How to run

### Step 1 - Download the dataset

👉 [Download movie dataset.csv](https://drive.google.com/file/d/1iJIxjywm5HxoYytJc0Wn_n-VqLXlIRTJY/view?usp=drive_link)

Place it in the project folder (same folder as `app.py`).

---

### Step 2 - Install dependencies

Open Terminal (macOS) or Command Prompt (Windows) in the project folder and run:

**macOS:**
```bash
pip3 install streamlit pandas numpy scikit-learn jupyter
```

**Windows:**
```bash
pip install streamlit pandas numpy scikit-learn jupyter
```

---

### Step 3 - Generate model files

Run the notebook to create `movies.db`, `tfidf_matrix.pkl` and `indices.pkl`:

```bash
jupyter notebook Movie_preprocessing.ipynb
```

In the browser: **Kernel → Restart & Run All.** Wait until all cells finish.

---

### Step 4 - Launch the app

```bash
streamlit run app.py
```

Opens automatically at `http://localhost:8501`
